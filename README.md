# Assignment 2: Portfolio Using External CSS

This repository contains the portfolio webpage styled with a separate external CSS file.

## Files

- `index.html` - portfolio webpage
- `style.css` - external stylesheet linked from `index.html`

## Run

Keep both files in the same folder, then open `index.html` in a web browser.
